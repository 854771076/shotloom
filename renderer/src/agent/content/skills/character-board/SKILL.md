# 角色板与三视图

只处理角色身份参考板，不负责剧本、分镜、连续视频、音频或画布制作流程。用户要求角色版、角色三视图、角色转面、角色设定版、character sheet、人物设定图或角色模卡时使用本 Skill。

## 固定版式

- 横向 16:9 单张角色开发板。
- 左侧放最大的人脸正面近景或半身正脸，清晰呈现五官、脸型、发型和身份锚点。
- 右侧按顺序放同一角色的正面、侧面、背面全身三视图。
- 三视图同尺度、脚底对齐、间距清楚，脸型、五官、体型、发型、服装和固定识别点一致。
- 背景使用干净的浅灰、米白或其他低干扰纯色，保留留白。
- 角色板只保留这四个主要区域：左侧大正脸，右侧正面、侧面、背面三视图。

“角色设定版”与“character sheet”默认指这套四区域版式，不等于带表情头像、装备拆解和色卡的扩展型概念板。除非用户明确写出“扩展角色板”并确认要增加区域，否则必须拒绝自行添加这些内容。

## 必须排除

不要生成单张半身海报、单人写真或无三视图的图片。不要加入额外头部角度、表情头像、服装配件拆解、装备特写、色卡、道具陈列、场景、装饰、网格、边框、参数表、长标签、水印、伪文字或重复人物。

## 提示词要求

提示词先描述可见的人物内容：年龄阶段、性别呈现、身材比例、脸型五官、肤色、发型发色、体态、服装层次、面料、剪裁、鞋靴、配饰和固定识别点，再补充写实或动画风格、光线和配色。只在用户明确要求时改变服装、时代或世界观。最后用简洁句子说明左侧大正脸和右侧三视图的排版与身份一致性。不要把“横向 16:9”“原创角色身份参考板”“角色名”“职业名”“角色设定版”等任务元数据写成提示词开头；角色名和职业只有在能转化为可见外观时才写入提示词。参考图明确展示的版式优先于通用概念设计惯例。

## 完成核验

完成前检查提示词是否同时包含左侧最大正脸、右侧正面/侧面/背面全身、纯色背景和三视图一致性；缺少任一项就先修正提示词。生成后确认画面没有多余人物、装饰或文字，并且三视图确实属于同一角色。
